# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or potential prompt injection bypass within `adaptive-radar-mcp`, please do **not** open a public issue.

Instead, please report it directly by opening a private security advisory on GitHub or by contacting the maintainer via GitHub Security Advisories.

Please provide:
- A description of the vulnerability and its potential impact.
- Exact steps to reproduce the issue (including any payload strings or test cases).
- Suggested remediation or patch, if available.

We will review reports within 48 hours and work toward a coordinated disclosure and patch release.
